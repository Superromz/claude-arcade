# Hero Roster

You can keep several heroes, like save slots. Each hero has its own look, class and progress.

![The roster with three heroes: a Knight, a Mage and a Rogue](https://raw.githubusercontent.com/Superromz/claude-arcade/main/docs/images/roster.png)

## Opening the roster

- The game opens on the roster whenever you already have a hero.
- Press `h` during the game to go back to it.

Each hero gets a card with an animated portrait, name, class, level, XP bar, quests, trophies, gold,
monsters slain and when you last played. The active hero is marked **▶ ACTIVE**.

## Keys

| Key | Action |
|---|---|
| `←` `→` (or `tab`) | Choose a hero |
| `Enter` | Play as this hero |
| `n` | Create a new hero (or press `Enter` on the "New Hero" card) |
| `e` | Edit this hero's look |
| `x`, then `x` again | Delete this hero and all of its progress. Any other key cancels |
| `q` / `Esc` | Quit |

You can't delete your last hero.

## What's separate per hero

Only the **active** hero earns XP from your Claude work. Switching heroes parks the current one's
progress and loads the other's.

| Separate for each hero | Shared by all heroes |
|---|---|
| XP and level | Daily streak |
| Quests completed | [Project stats](Project-Stats) |
| Tool counts and stats | Theme and settings |
| Achievements | |
| Tokens and token XP | |
| Gold, kills and inventory | |

## Upgrading from an older version

If you played before the roster existed, your existing hero and all of its progress become the
first hero on the roster automatically.

# Skill Tree

Monsters get tougher with every wave and every level, so your hero needs to grow in more than
numbers. The **Skills** tab (tab 3) holds your class's skill tree.

## Points

- **1 point per hero level**, plus **1 point per boss defeated**.
- Points are per hero: every hero on the [Hero Roster](Hero-Roster) builds their own tree.

## Branches

Each class has **3 branches of 5 nodes**. The last node of each branch is a **capstone**, and
nodes open by tier (levels 1, 4, 8, 12 and 16). Each node needs the one above it.

Node effects include more damage for a skill, extra targets, shorter cooldowns, faster attacks,
longer effects, damage over time, and on-hit burn, stun, bleed or lifesteal. Some nodes are tied
to how you use Claude, e.g. *Firestarter: edits deal +15% damage per rank*.

Capstones and special nodes change how a skill works:

| Class | Examples |
|---|---|
| Mage | Phoenix Fire (Fireball splits into 3), Starstorm (Starfall strikes twice) |
| Ranger | Deadeye (crits deal ×3), Arrowstorm (Rain of Arrows covers the field) |
| Knight | Bladestorm (Whirlwind spins twice), Final Judgment (double damage to bosses) |
| Warlock | Plague (curses spread on death), Twin Imps |
| Bard | Epic Ballad (Anthem adds crit), Wall of Sound, Double Echo |
| Rogue | Assassinate (Backstab executes below 30% HP), Pandemic, Shadow Clone |

## Respec

Press `r` on the Skills tab to refund every point. It costs gold: **100, then 200, 400, …**
(doubling each time) and asks you to confirm.

## Paragon

Once every rank in your tree is learned, each new point becomes a **paragon point** for a small
permanent boost with no cap: **Might** (+1% damage), **Fortune** (+1% gold) or **Precision**
(+1% crit). Paragon points survive a respec.

## Controls

| Key | Action |
|---|---|
| `↑↓←→` | Move between nodes |
| `Enter` | Learn a rank |
| `r` | Respec (asks to confirm) |

The tree never grants XP. XP only comes from real Claude usage.
